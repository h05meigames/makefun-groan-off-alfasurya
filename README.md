A [make.fun](https://make.fun/c/u-alfasurya91-the-one-liner-groan-off-5a1febd5) bounty entry for **The One-Liner Groan-Off** — one original one-line dad joke, at most 140 characters, plain text.

## The entry

> `Our printer finally got a promotion: after years of jamming, it really made an impression.`

90 characters. Run it:

```sh
node main.ts
```

`main.ts` prints the line to stdout and also writes it to `/output/entry.txt`
(the path the make.fun program/v1 harness reads). It validates the gate
itself — 1–140 characters, one line, not only whitespace — and exits non-zero
if the entry ever fails it. Running it twice produces byte-identical output.
